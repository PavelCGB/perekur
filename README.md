# Перекур

Таймер между перекурами для Android. Ставишь перерыв, например 2 часа, жмёшь «Покурил», и приложение пришлёт уведомление со звуком, когда можно снова. Уведомление приходит, даже если телефон заблокирован.

Вкладка «Мой день» показывает, сколько сигарет выходит в день с таким перерывом, расписание по часам и сколько денег ты экономишь.

## Установка

Скачай `Perekur.apk` из раздела Releases, открой файл на телефоне и разреши установку из этого источника.

## Сборка

```
cd android
gradlew assembleDebug
```

Нужны JDK 17+ и Android SDK. Интерфейс лежит в `perekur.html`. Перед сборкой его копия кладётся в `android/app/src/main/assets/index.html`.
